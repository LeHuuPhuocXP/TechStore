#  TechStore - Website Bán Thiết Bị Điện Tử

## Giới thiệu

**TechStore** là đồ án môn học được phát triển bằng **Python Django**, xây dựng một website thương mại điện tử chuyên kinh doanh các thiết bị điện tử như điện thoại, laptop, máy tính bảng, tai nghe, đồng hồ thông minh và các phụ kiện công nghệ.

Hệ thống cung cấp đầy đủ các chức năng của một website bán hàng trực tuyến, bao gồm quản lý sản phẩm, giỏ hàng, thanh toán, quản lý đơn hàng và trang quản trị dành cho quản trị viên.

---

## Mục tiêu

* Xây dựng website thương mại điện tử bằng Django theo mô hình MVC (MVT).
* Áp dụng kiến thức về Django, HTML, CSS, JavaScript và Bootstrap.
* Thực hiện quản lý dữ liệu bằng MySQL.
* Triển khai các chức năng bán hàng trực tuyến.
* Tạo giao diện thân thiện và dễ sử dụng.
